# Privacy

The current OpenShelf prototype is a static website. It does not create user accounts, accept uploads, run a catalogue database, or intentionally collect search queries. Search and filters run locally in your browser.

External links open third-party websites. Those sites have their own privacy policies, cookies, analytics, availability, and terms. GitHub Pages may process technical request logs as part of hosting.

If a future version adds accounts, analytics, file uploads, or email delivery, it must publish an updated privacy notice before launch, including what data is collected, why it is needed, retention periods, service providers, user controls, and a contact route. Never ask for or store a user's Amazon password.
